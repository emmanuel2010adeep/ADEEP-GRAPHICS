# Adeep Graphics — AG

A premium black-and-gold video editor portfolio built with **Python (Flask)**, **HTML/Jinja**, **CSS**, and **JSON**.

## Run locally

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open `http://localhost:5000`.

## Add your real work

Edit `data/content.json` and add the URLs for your short-form showreel, wedding projects, real-estate projects, long-form projects, and social/contact links. The page is data-driven, so normal content updates do not require editing the layout.
